Install Kestrel Drone

It's free and runs in your browser. Add it to your home screen or computer to open it like any other app.

Use it in your browser

Open the app. Nothing to install and no account.

Open Kestrel Drone

iPhone and iPad

  1. Open app.drone.kestrelaviation.tech in Safari.
  2. Select Share, then Add to Home Screen.
  3. Allow location access when asked, to check where you are.

Android

  1. Open app.drone.kestrelaviation.tech in Chrome.
  2. Open the menu and select Add to Home screen, or Install app.
  3. Allow location access when asked.

Mac and Windows

  1. Open app.drone.kestrelaviation.tech in Chrome or Edge.
  2. Select the install icon at the right end of the address bar.

Without a connection

Once installed, the app opens without a connection and keeps the airspace data for areas you've already loaded. The base map, weather, TFRs and NOTAMs need a connection, so check your spot again before you fly.
